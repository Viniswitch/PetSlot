# Definition of Done (DoD)

Critério de "pronto" válido para **todo o projeto**, aplicado a todas as sprints — não é redefinido a cada sprint, apenas revisado nas Retrospectivas se necessário.

Uma história só é movida para **Done** no board quando:

1. O critério de aceite (BDD) foi executado como caso de teste
2. Não há bug de severidade **Alta (P0)** ou **Média (P1)** em aberto vinculado à história (ver campo "Relationships" da issue)
3. Bugs de severidade **Baixa (P2)** podem ser aceitos como dívida técnica, desde que a decisão seja registrada explicitamente em comentário na issue (não é aceite automático)
4. A história foi revisada por outro integrante do grupo, diferente de quem a implementou/detalhou
